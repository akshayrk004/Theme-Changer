Theme Changer

A simple Theme Changer web project built using HTML, Tailwind CSS, and Font Awesome.
This project provides a button to switch between light mode and dark mode.

Features


Toggle between Light Mode and Dark Mode
Responsive UI using Tailwind CSS
Font Awesome icons
Beginner-friendly project structure


Technologies Used

HTML5
Tailwind CSS
Font Awesome
JavaScript
